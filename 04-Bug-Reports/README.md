# Sales & Delivery – Bug Reports

## Overview

This section contains selected bug reports identified during manual QA testing of the ERP Sales & Delivery module.

The portfolio focuses on defects found within the:

- Sales Quotation workflow
- Sales Order workflow
- Quotation-to-Order integration

The purpose of these reports is to demonstrate how defects were documented with clear reproduction steps, expected behavior, actual behavior, severity, priority, and supporting evidence.

---

## Bug Categories Covered

Selected defects may include:

- Validation issues
- Business rule violations
- Calculation errors
- Workflow / status transition issues
- Quotation-to-Order data inconsistencies
- Search and filter issues
- Permission and authorization issues
- UI / UX problems
- Duplicate transaction issues
- Error handling problems

---

## Bug Report Structure

Each bug report includes:

- Bug ID
- Bug Title
- Module / Feature
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Evidence / Screenshot

## Integration Bugs

Special attention is given to issues affecting the:

**Sales Quotation → Sales Order**

workflow, including:

- Missing or incorrect quotation references
- Incorrect data transfer
- Customer / contact mismatches
- Pricing inconsistencies
- Tax / discount inconsistencies
- Duplicate Sales Order creation
- Incorrect workflow states

## Evidence

Supporting screenshots are stored in the `Evidence` folder and named according to the related Bug ID.
